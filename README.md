# Mnem

**Mnem** (named after Mnemosyne, the Greek goddess of memory) is a simple, asynchronous, in-memory key-value data store written in Rust.

> [!WARNING]
> **For Fun & Learning Only!**
> This project was built entirely for educational purposes, exploration, and the sheer joy of programming in Rust. It is **not** intended for professional, production, or commercial usage. It's a playground to learn about async Rust, TCP networking, and the RESP protocol.
